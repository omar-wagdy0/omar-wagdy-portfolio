PROJECT IMAGE SETUP

Each project has a cover.svg used on the Projects grid. You can replace cover.svg with your own JPG/PNG if you update the cover <img> path in index.html.

CASE STUDY GALLERIES
- Excel and Power BI projects currently expect 01.svg, 02.svg, 03.svg.
- SQL Code Library expects 01.svg through 06.svg. Replace these placeholder SVGs with your real screenshots, or rename the files to 01.png etc. and update data-ext in the project page.
- The gallery is flexible: add another image filename to the images array/count in the page and the side preview, main image, thumbnails and counter will automatically adapt.
- Layout is responsive; images are not hard-coded into a fixed number of cards.

Recommended real screenshot formats: JPG, PNG or WebP. Keep the same aspect ratio where possible for the smoothest carousel.
