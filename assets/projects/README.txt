PROJECT IMAGE SETUP

Each project has one cover.svg for the main Projects grid. Replace that file with your real cover image if you prefer, or update the cover <img> path in index.html.

FLEXIBLE CASE-STUDY GALLERIES
- MISUO Sales Furniture, Customer Churn Rate, Service Company, Power Consumption and Weather APIs: 3 images are ready as 01.svg, 02.svg, 03.svg.
- SQL Code Library: 6 images are ready as 01.svg through 06.svg for your SQL code screenshots.
- The carousel automatically builds its thumbnails, side-blur previews and counter from the image count.
- To add a new image, add the next numbered file (for example 04.png) and change ONLY the imageCount in that project page. The layout automatically creates the space for it.
- If you switch from SVG to PNG/JPG/WebP, change data-ext on that project page (for example data-ext="png").
- Recommended real screenshot formats: PNG/JPG/WebP.
